# Filtered Anime and Manga Discovery

Use `anilist_filtered_discovery` when the user asks for recommendations or a broad set of titles by genre, country, format, release status, or season. AniList applies popularity and score sorting and returns at most ten results. For a year filter, provide both season and year because the API requires them together. State the filters used and retain each AniList source link.

This skill does not infer taste or quality from the ranking; explain that the ordering reflects AniList's popularity/score fields.
