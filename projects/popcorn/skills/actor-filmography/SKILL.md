# Person credits

Search for the person with `search_people`. When the result is unambiguous, use `get_person_movie_credits` for a movie-only request, or `get_person_combined_credits` for TV or cross-media credits. If the search is ambiguous, show candidates and ask the user to choose. Present these as credits listed by TMDB, not as a complete or definitive filmography. Include the TMDB source link.
